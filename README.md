# 🔍 Real-Time Fraud Detection System with MLOps

Production-grade fraud detection ML platform — Multi-layer ensemble 
(XGBoost + Neural Network + Graph Anomaly Detection) with full MLOps pipeline.

## Results
- 30% fraud detection accuracy improvement
- 22% false positive reduction → $4M+ annual savings  
- 100K+ inference requests/hour at p99 < 80ms
- Automated retraining triggered by PSI drift detection

## Tech Stack
Python | XGBoost | PyTorch | PySpark | MLflow | Kubeflow | 
AWS SageMaker | EKS | FastAPI | Kubernetes | Airflow

## Project Structure
- src/models/ensemble.py — Multi-layer stacking ensemble
- src/models/train.py — MLflow training pipeline
- src/monitoring/drift_detector.py — PSI drift detection
